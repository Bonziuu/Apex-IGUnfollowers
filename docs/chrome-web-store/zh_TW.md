# Apex Unfollowers – Instagram 回追與退追查詢

## Short description

查看 Instagram 上誰沒有回追你、誰取消了對你的追蹤。資料在瀏覽器內處理，無須向擴充功能提供密碼。

## Full description

想知道 Instagram 上誰沒有回追你嗎？Apex Unfollowers 會比對粉絲與追蹤中名單，讓你看出哪些帳號沒有回追你、哪些粉絲你還沒回追，以及哪些帳號和你互相追蹤。再次掃描後，也能查看自上次掃描以來的新增粉絲和取消追蹤你的帳號。

• 可依名稱搜尋，並以驗證狀態、是否公開及有無大頭貼照來篩選。也能將品牌或名人等帳號加入排除清單，從未回追名單中隱藏。
• 利用趨勢圖查看粉絲人數，也能查看最近 7 天和 30 天的增減。
• 掃描較長的名單時會顯示預估剩餘時間。掃描中斷後，可以從上次儲存的進度繼續。
• 將目前分頁的篩選結果匯出為 CSV，並使用 JSON 檔案備份掃描結果、歷史記錄和設定。
• 取消追蹤須逐一手動確認，且設有操作間隔及每日上限。

資料會在瀏覽器內處理，結果與設定保存在本機。使用前請先登入 instagram.com。擴充功能使用你已登入的工作階段，無須另外註冊，也無須向擴充功能提供密碼。擴充功能不會將遙測資料傳送給開發者，原始碼公開於 GitHub。介面支援繁體中文等 20 種語言，以及淺色與深色主題。

這款擴充功能使用 Instagram 網頁的非官方 API。初次使用時會說明帳號使用的注意事項。Apex Unfollowers 是獨立專案，與 Instagram 或 Meta Platforms 無隸屬或合作關係。
