# Apex Unfollowers – Instagram 回关与取关查询

## Short description

查看 Instagram 上谁没有回关你、谁取关了你。数据在浏览器本地处理，无需向扩展提供密码。

## Full description

想知道 Instagram 上谁没有回关你？Apex Unfollowers 对比你的粉丝列表和关注列表，找出没有回关你的账号、你没有回关的账号，以及互相关注的账号。再次扫描后，还能看到自上次扫描以来新增的粉丝和取关你的账号。

• 按名称搜索，按认证状态、公开状态或有无头像筛选。可把品牌、名人等账号加入白名单，让它们不出现在未回关的列表中。
• 用趋势图查看粉丝数量变化，并查看最近 7 天和 30 天的增减。
• 扫描较长的列表时会显示预计剩余时间。扫描中断后，可以从保存的进度继续。
• 将当前标签页的筛选结果导出为 CSV，并使用 JSON 文件备份扫描结果、历史记录和设置。
• 取消关注需手动逐个确认，并受操作间隔和每日上限限制。

扩展在浏览器中处理数据，结果和设置保存在本地。使用时须登录 instagram.com，可以直接使用当前登录会话，无需另行注册，也无需向扩展提供密码。扩展不会向开发者发送遥测数据，源代码在 GitHub 公开。界面支持简体中文等 20 种语言，并提供浅色和深色主题。

扩展使用 Instagram 网页的非官方 API，首次使用时会说明与账号相关的注意事项。Apex Unfollowers 是独立项目，与 Instagram 或 Meta Platforms 无隶属或合作关系。
