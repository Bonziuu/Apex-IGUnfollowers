# Apex Unfollowers – Instagramのフォロー管理

## Short description

Instagramでフォローバックしていない相手やフォローを外した相手を確認。ブラウザ内で処理され、パスワードの入力は不要です。

## Full description

Instagramでフォローバックしていないのは誰？ Apex Unfollowersは、あなたのフォロワーとフォロー中のリストを比較し、フォローバックしていない相手、自分がフォローバックしていない相手、相互フォローの相手を表示します。スキャンを再度実行すると、前回のスキャン以降にフォローを外した相手や、新しくフォローした相手を確認できます。

• アカウント名で検索し、認証済み、公開・非公開、プロフィール写真の有無などで絞り込めます。ブランドや有名人などは除外リストに追加できます。
• フォロワー数の推移をグラフで見たり、過去7日間と30日間の増減を確認したりできます。
• 件数の多いリストのスキャンでは、残り時間の目安が表示されます。途中で止めても、保存済みの進捗から再開できます。
• 表示中のリストをCSVで書き出し、結果、履歴、設定をバックアップできます。
• フォロー解除は手動で1件ずつ行います。実行前の確認、操作間隔、1日の上限が設けられています。

データはブラウザ内で処理され、結果と設定は拡張機能に保存されます。instagram.comへのログインが必要ですが、すでにブラウザでログインしていればそのセッションを使用します。拡張機能への登録、パスワード入力、利用状況データの開発者への送信はありません。ソースコードはGitHubで公開されています。日本語を含む20言語とライト・ダークテーマに対応しています。

この拡張機能はInstagramの非公式ウェブAPIを使用します。初回利用時にアカウントへの影響に関する注意事項をご案内します。Apex UnfollowersはInstagramおよびMeta Platformsの公式製品ではない独立したプロジェクトです。
