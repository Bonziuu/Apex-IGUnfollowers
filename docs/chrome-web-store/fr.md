# Apex Unfollowers pour Instagram

## Short description

Découvrez qui ne vous suit pas sur Instagram et qui s’est désabonné. Analyse locale des abonnés, sans saisir votre mot de passe.

## Full description

Apex Unfollowers compare vos abonnés et vos abonnements sur Instagram. Découvrez qui ne vous suit pas en retour, qui vous ne suivez pas et quels abonnements sont réciproques. À partir de la deuxième analyse, retrouvez les nouveaux abonnés et les désabonnements depuis la précédente.

- Recherchez les comptes par nom, triez-les et filtrez-les par type de profil. Masquez les marques et autres comptes avec une liste d’exclusion.
- Consultez le graphique des abonnés, l’historique des analyses et le bilan sur 7 et 30 jours.
- Reprenez une analyse interrompue, exportez la liste affichée en CSV et sauvegardez vos données dans un fichier JSON.
- Vous pouvez vous désabonner d’un compte à la fois, après confirmation. L’extension impose une pause entre les actions et une limite quotidienne.

Pour commencer, ouvrez le panneau Apex après vous être connecté sur instagram.com. L’extension utilise votre session Instagram ouverte, sans vous demander de créer un compte Apex ni de saisir votre mot de passe. Les résultats, l’historique et les réglages restent dans votre navigateur. Le code source est public sur GitHub et Apex ne collecte aucune donnée de télémétrie.

Le panneau est disponible en 20 langues et adopte le thème clair ou sombre de votre système.

Apex Unfollowers est un projet indépendant d’Instagram et de Meta.
