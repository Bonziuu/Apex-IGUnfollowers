# Apex Unfollowers – Instagram 팔로워 관리

## Short description

Instagram에서 누가 나를 맞팔로우하지 않는지, 누가 언팔로우했는지 확인하세요. 데이터는 브라우저에서 처리되며 비밀번호 입력이 필요 없습니다.

## Full description

Instagram에서 누가 나를 맞팔로우하지 않는지 궁금하신가요? Apex Unfollowers로 팔로워와 팔로잉 목록을 비교해 나를 맞팔로우하지 않는 계정, 내가 맞팔로우하지 않는 계정, 서로 팔로우하는 계정을 확인할 수 있습니다. 다시 스캔하면 지난 스캔 이후 나를 언팔로우했거나 나를 새로 팔로우한 계정도 볼 수 있습니다.

• 이름으로 검색하고 인증 여부, 공개 여부, 프로필 사진 유무로 목록을 필터링하세요. 브랜드나 유명인 계정을 제외 목록에 추가할 수도 있습니다.
• 그래프에서 팔로워 수의 변화와 최근 7일 및 30일 동안의 변동을 확인하세요.
• 목록이 길면 예상 남은 시간을 확인할 수 있습니다. 스캔을 중단했다면 저장된 진행 상황을 불러와 계속할 수 있습니다.
• 현재 탭의 필터 결과를 CSV로 내보내고 스캔 결과, 기록, 설정을 JSON 파일로 백업하세요.
• 언팔로우는 확인 후 한 계정씩 수동으로 진행합니다. 작업 사이에 대기 시간이 있으며 하루 한도가 적용됩니다.

데이터는 브라우저에서 처리되고 결과와 설정은 확장 프로그램에 저장됩니다. instagram.com에 로그인한 상태에서 이용하며, 확장 프로그램 자체의 계정을 만들거나 비밀번호를 입력할 필요가 없습니다. 개발자에게 사용 정보를 전송하지 않으며 소스 코드는 GitHub에 공개되어 있습니다. 한국어를 포함한 20개 언어와 밝은 테마 및 어두운 테마를 지원합니다.

확장 프로그램은 Instagram의 비공식 웹 API를 사용합니다. 처음 시작할 때 계정 이용에 관한 주의 사항을 안내합니다. Apex Unfollowers는 Instagram 또는 Meta Platforms와 제휴하지 않은 독립 프로젝트입니다.
