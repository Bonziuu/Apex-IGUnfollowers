# Apex Unfollowers สำหรับ Instagram

## Short description

ดูว่าใครไม่ติดตามกลับและใครเลิกติดตามคุณบน Instagram ข้อมูลอยู่ในเบราว์เซอร์และไม่ต้องให้รหัสผ่าน

## Full description

ใครไม่ได้ติดตามคุณกลับบน Instagram? Apex Unfollowers เปรียบเทียบรายชื่อผู้ติดตามกับบัญชีที่คุณติดตาม เพื่อให้คุณเห็นว่าใครไม่ได้ติดตามคุณกลับ คุณไม่ได้ติดตามใคร และบัญชีไหนติดตามกันทั้งสองฝ่าย เมื่อสแกนอย่างน้อยสองครั้ง ประวัติการเปลี่ยนแปลงจะแสดงว่าใครเริ่มติดตามหรือเลิกติดตามคุณตั้งแต่การสแกนครั้งก่อน

• ค้นหาตามชื่อ เรียงลำดับรายชื่อ หรือกรองบัญชีที่ยืนยันแล้ว บัญชีส่วนตัว บัญชีสาธารณะ และบัญชีที่ไม่มีรูปโปรไฟล์
• ดูกราฟจำนวนผู้ติดตามตามเวลาและยอดเปลี่ยนแปลงสุทธิในช่วง 7 และ 30 วัน
• เพิ่มบัญชีของแบรนด์หรือคนดังในรายการยกเว้นเพื่อซ่อนจากรายชื่อผู้ที่ไม่ได้ติดตามกลับ
• ยืนยันก่อนเลิกติดตามทีละบัญชี โดยมีช่วงพักระหว่างรายการและขีดจำกัดต่อวันที่ปรับได้
• สแกนต่อจากจุดที่หยุด ส่งออกรายชื่อเป็น CSV หรือสำรองรายชื่อ ประวัติ และการตั้งค่าเป็นไฟล์ JSON
• ใช้งานเป็นภาษาไทยหรือภาษาอื่นที่รองรับ โดยธีมสว่างหรือมืดจะเปลี่ยนตามการตั้งค่าของเบราว์เซอร์

ส่วนขยายใช้การเข้าสู่ระบบ Instagram ที่เปิดอยู่แล้วในเบราว์เซอร์ ไม่ต้องสมัครบัญชีเพิ่มและไม่ต้องให้รหัสผ่านกับส่วนขยาย ผลการสแกน ประวัติ และการตั้งค่าอยู่ในเบราว์เซอร์ของคุณ โดยไม่ส่งข้อมูลการใช้งานไปยังผู้พัฒนา ดูซอร์สโค้ดได้สาธารณะบน GitHub

ส่วนขยายจะดึงรายชื่อจาก Instagram เมื่อเริ่มสแกน Instagram อาจจำกัดการดำเนินการในบัญชีของคุณ หน้าต้อนรับมีคำแนะนำเมื่อเริ่มใช้งาน Apex Unfollowers เป็นโครงการอิสระที่ไม่มีความเกี่ยวข้องกับ Instagram หรือ Meta
